# Lesson 19 — GitHub Collaboration Tools: Issues, Projects, Discussions

GitHub is more than code hosting. It is also a planning and communication workspace.

## Learning Goals
By the end of this lesson, you will be able to:
- Use Issues to track bugs/features/tasks
- Organize work with Projects
- Use Discussions for longer-form Q&A
- Apply labels and milestones for clarity

## Simple Explanation
Use each tool for a specific purpose:
- Issues: actionable work items
- Projects: planning board and workflow tracking
- Discussions: open-ended conversation and support

## Recommended Conventions
- Write issue titles as clear actions or problems
- Use labels (`bug`, `feature`, `docs`, `priority`)
- Link PRs to issues
- Keep project board statuses current

## Optional GitHub CLI Commands
```bash
gh issue list
gh issue create --title "Example task" --body "Details"
```

- Treating Discussions as task trackers
- Letting project boards go stale
