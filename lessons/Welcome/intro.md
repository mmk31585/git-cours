## 🧠 Simple Explanation

### What is Git?
**Git is a version control system** — a tool that tracks changes in your files over time.  
It works like a **time machine for your code**: you can save checkpoints and go back anytime.

✅ Git helps you:
- Track every change
- Recover older versions
- Experiment safely
- Work with others without overwriting each other

### What is GitHub?
**GitHub is a platform that hosts Git repositories online** and adds collaboration features like:
- Pull Requests (PRs)
- Code Reviews
- Issues (task/bug tracking)
- Discussions and Projects

> Git is the engine. GitHub is the collaboration space.

---

### With Git ✅
- Every meaningful change becomes a **commit (checkpoint)**
- You can **undo** mistakes safely
- You can develop features in **branches**
- Teams merge work through **pull requests**

---

## 🧾 Key Vocabulary (Quick & Practical)
| Term | Meaning (simple) |
|------|-------------------|
| Repository (repo) | The project folder + its Git history |
| Commit | A saved checkpoint of changes |
| Branch | A separate line of work (feature sandbox) |
| Merge | Combine changes from branches |
| Remote | The online copy of your repo (often GitHub) |
