# Exercise — Lesson 19: GitHub Collaboration Tools

Practice goal: organize tasks with Issues, Projects, and Discussions.

## Part A: Create structured issues
In GitHub UI, create:
- 1 bug issue
- 1 feature issue
- 1 docs issue

For each issue add:
- clear title
- problem statement
- expected outcome

## Part B: Add labels and milestone
1. Add labels like `bug`, `feature`, `docs`, `priority`.
2. Create a milestone and assign issues.

## Part C: Project board
1. Create or open project board.
2. Add issues to board columns (Todo, In Progress, Done).

## Part D: Discussion
1. Open a Discussion for non-task topic (for example roadmap question).

## Self-Check
- [ ] I created issues with clear scope
- [ ] I labeled and grouped issues
- [ ] I placed tasks in a project board
- [ ] I used Discussion for non-task conversation
