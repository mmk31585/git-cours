# Git & GitHub Workshop: From Zero to Hero

A practical, lesson-by-lesson Git course focused on real workflow habits.

## Quick Start
```bash
git --version
```
If Git is not installed, start with Lesson 02.

## Core Concepts
- Track code history with small, meaningful commits.
- Use branches to keep work isolated from `main`.
- Review and merge changes through pull requests.
- Resolve conflicts safely and keep history readable.
- Sync correctly with remotes (`fetch`, `pull`, `push`).
- Protect repositories with `.gitignore`, reviews, and clear conventions.

## How To Use This Repo
1. Open the lesson README.
2. Complete the matching exercise task.
3. Commit your work with clear messages.
